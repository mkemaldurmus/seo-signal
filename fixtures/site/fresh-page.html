A perfectly current page

This page states things that are true and makes no absolute claims about anyone else's product. It links to another page.

Why this section exists

Real landing pages are a few thousand bytes of prose, and several of the scripts here deliberately skip files below a size floor so that stubs, redirects and verification files do not pollute a report. A fixture that is smaller than a real page would therefore test a path no user ever hits.

So this filler is not decoration. It puts the fixture on the same side of that threshold as the pages the tool is actually pointed at, which is what makes the assertions in test/scripts.test.mjs meaningful.
